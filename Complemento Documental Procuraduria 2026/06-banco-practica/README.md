# Banco de preguntas: política editorial
- Toda pregunta debe tener un identificador estable, área, enunciado, cuatro opciones, respuesta, justificación, fuente jurídica y fecha de verificación.
- Marcar `EJEMPLO` hasta que un responsable coteje artículo y vigencia. Jamás atribuir a la Procuraduría preguntas generadas aquí.
- Si cambia una ley, versionar la pregunta o archivarla; no cambiar silenciosamente la respuesta.
- Banco CSV inicial adjunto con preguntas introductorias de demostración (no examen oficial).
